化粧品ブランドを作りたい。何から始める？｜
OEMに相談する前に知っておきたい
7つのつまずき

公開日：2026年11月21日 更新日：2026年11月21日 著者：湯浅 茉奈（Milien株式会社 代表）

導入：失敗は、工場ではなく企画で起きる

OEMに問い合わせたものの、希望ロットを聞かれて答えられない。試作が届いたけれど、どこを直してほしいか言葉にできない。一人で化粧品を企画していて、動いているのに進まないと感じたら、まず「次に何を決めるべきか」を整理するところからです。

一人で企画していると、自分の案をレビューしてくれる相手がいません。OEM工場は相談に乗ってくれますが、工場の仕事は「頼まれたものを作ること」です。コンセプトの良し悪しや、売れるかどうかまでは判断してくれません。

この記事では、作りたい人が詰まりやすい7つのパターンを、詰まる順番に並べて解説します。先に結論を言うと、つまずきのほとんどは「企画を固める前に、工場・容器・数量を決めに走る」ことに集約されます。

今困っている箇所から読んでも大丈夫です。費用・在庫なら第2章／コンセプトなら第3章／工場の提案や試作なら第4章／言える訴求なら第6章／売り方なら第7章へどうぞ。

第1章 何から始めるか、順番が分からない

OEM会社への最初の相談で最も多いのが、「何から始めればいいか分からない」という声だと言われます。決めること自体が多いうえに、順番を間違えると後から全部やり直しになるのが、化粧品づくりの難しいところです。

決める順番の地図は、大きくこうなります。

  1. 誰の、どんな悩みに応える商品か（コンセプト）
  2. その悩みに応える中身の方向性（処方の軸）
  3. いくつ作って、いくらで売るか（数量と価格）
  4. それに合う容器
  5. 製造を任せる工場

よくある失敗が、4の容器を先に決めてしまうことです。「このボトルが可愛いから使いたい」と容器から入ると、中身の量も、原価も、売る価格も、全部容器に引きずられます。容器は中身と販売計画が決まってから選ぶものです。順番を守るだけで、やり直しの多くは防げます。

第2章 いくつ作るか、いくらかかるか分からない

費用の不安は、作りたい人の一番大きな悩みです。「化粧品 OEM 費用」「小ロット」といった検索が多いのも、その表れです。

ロット・在庫の見誤り

単価を下げたいからと、作る数量（ロット）を増やしすぎる失敗はとても多く見られます。単価は確かに下がります。でも、売り切れなければ在庫が残り、化粧品には使用期限があるので、期限が来れば廃棄にもお金がかかります。「安く作れた」ではなく「いくら回収できたか」で見ることが大切です。最初は売り切れる量から始めて、売れ行きを見て増やす方が、結果的に損失は小さくなります。

見積もりの相場と内訳の見方

見積もりを見るときに多い誤解が、「中身の製造費＝OEMにかかる費用の全部」という思い込みです。実際には、容器代、化粧箱などの包材代、充填の費用、検査や届出に関わる費用などが別に乗ってきます。総額だけを見て「高い・安い」を判断するのではなく、内訳が書かれているか、何が含まれていないかを確認してください。内訳を出してくれるかどうか自体が、工場を見分ける材料になります。

容器と費用は一緒に決まる

容器は見た目だけでなく、費用と中身の両方に効きます。高級感のある容器は単価を押し上げますし、中身の性質（光に弱い、空気に触れると劣化する等）によって使える容器が限られることもあります。第1章の順番どおり、中身と価格が決まった段階で、費用と合わせて選ぶのが正解です。

なお、Milienで企画のご相談をお受けする目安は、想定ロット1,000個以上です。

第3章 コンセプトがふわっとしていて差別化できない

「敏感肌向けの、やさしい化粧水」——これでは差別化できません。同じことを言っている商品が、市場に何百とあるからです。

背景にあるのは、市場調査やリサーチをせず、「作りたいもの」から考えるプロダクトアウトの発想です。「良いものを作れば売れるはず」で進めると、ターゲットが決まらないまま、悩みや需要のないところに商品を作ることになります。順番は逆で、まず「誰の・どんな悩みに応えるか」があり、その答えとして商品があります。

コンセプトは、次の3点で言い切れるかどうかが基準です。

  • 誰の（どんな人が）
  • どんな悩みに（どんな場面で困っているか）
  • 何で応えるか（成分・処方・使い方のどこが違うか）

3点目が「良い成分をたくさん入れました」では弱いです。成分は手段であって、差別化は「その人の悩みに、なぜこの処方なのか」の説明がついて初めて成立します。逆に、この3点が言い切れる商品は、広告の言葉も、パッケージの文言も、自然に決まっていきます。

第4章 OEMの提案を、商品価値で評価できない

工場から処方の提案が返ってきたとき、「何となく良さそう」で決めてしまう人が少なくありません。

知っておいてほしいのは、工場の提案には工場側の事情が入ることです。工場は、安定して作れること、効率よく生産できることを優先して提案します。それ自体は当然のことで、悪いことではありません。ただ、「安定して作れる処方」と「コンセプトに合った、売れる処方」は別物です。提案を評価するには、自分のコンセプトに照らして比べる物差しが要ります。

試作のブレ

試作の段階で起きやすいのが、「もう少ししっとりさせたい」「もう少しさっぱり」といったあいまいな伝え方で試作を繰り返し、回数と期間と予算が膨らんでいくパターンです。試作は回数に上限がある契約も多く、あいまいな指示はそのままコストになります。「しっとり」の度合いを、ベタつき・伸び・塗った後の感触など、具体的な言葉に置き換えて伝えることが、試作を早く終わらせるコツです。

第5章 成分・処方の良さを、買う理由に変えられない

作り手が陥りやすいのが、処方の説明をそのまま商品の売り文句にしてしまうことです。「○○成分配合」「独自処方」といった言葉は、作り手には響いても、買う人には「で、私に何がいいの？」で終わります。

必要なのは、処方の言語を使い手の言語に翻訳する作業です。たとえば、成分の名前を言うのではなく、その成分が「朝のメイク前に使っても邪魔しない」「乾燥で粉がふく頬に、夜の最後に重ねられる」といった、使う場面と困りごとの解決として語れるかどうか。この翻訳ができるかどうかで、同じ中身でも「買う理由」の強さが変わります。

第6章 言いたい訴求が薬機法で言えるか分からない

化粧品で言える効能には範囲が決まっていて、認められた56項目の範囲を超える表現は使えません。「シミが消える」「若返る」といった言い方は、化粧品では言えない表現です。

怖いのは、商品ができてから「その売り文句は言えません」と分かることです。コンセプトの核が言えない表現だった場合、コンセプトから作り直しになります。だからこそ、言いたい訴求が言える範囲かどうかは、企画の早い段階で確認しておく必要があります。

なお、表現の適法性の判定（リーガルチェック）は、Milienでは行いません。ただ、企画の段階で「どの表現が際どいか」「どの段階で専門家に確認すべきか」を先に整理しておくことはできます。

第7章 売り方が決まっていない／価格競争から抜けられない

誰に、どの販路で、いくらで売るか。これが決まっていないと、第2章の数量も容器も決まりません。ECで売るのか、店舗に置くのか、定期購入なのかで、作る量も、パッケージの作り方も、価格の付け方も変わります。

価格競争に巻き込まれる商品の多くは、「誰の・どんな悩みに」が曖昧なまま、似た商品と並んで価格で比べられている状態です。逆に、悩みと応え方が言い切れている商品は、価格以外の理由で選ばれます。売り方とコンセプトは、別々に考えるものではなく、最初にセットで決めるものです。

じゃあ、どうすればいいか

7つのパターンは、どれも「決める順番」と「判断の物差し」があれば避けられます。具体的にやることは3つです。

  1. 決める順番を先に決める：コンセプト → 中身の方向性 → 数量と価格 → 容器 → 工場。この順番を飛ばさない
  2. 判断の物差しを持つ：コンセプトは「誰の・どんな悩みに・何で応えるか」の3点、見積もりは総額ではなく内訳、訴求は言える表現の範囲で見る
  3. 一人で決めない部分を決めておく：自分で判断できることと、第三者の目があった方がいいことを分ける。一人企画の失敗の多くは、能力ではなく「レビューする相手がいない」ことから起きます

たとえば、OEMから2社分の見積もりが来て、どちらを選ぶか迷っているとします。まず金額の前に、予定の販売価格で無理なく始められる数量か、容器や充填まで同じ条件で比較できているかを見ます。そこで初めて、工場を選ぶ段階なのか、先に数量や仕様を見直す段階なのかが分かります。

Milienができること

Milienは、この3つを企画の段階から一緒にやる会社です。

  • 企画の設計：コンセプトの3点が言い切れるところまで詰め、処方の良さを「買う理由」に変える言葉まで設計します
  • 順番と判断の整理：何が決まっていて何が決まっていないかを並べ、次に決めるべきことを決めます
  • OEM選定の伴走：企画が固まった後、作りたい量（ロット）や作りたい商品に合わせて、合う工場を一緒に探します

まとめ：最初に直すのは「順番」

7つのパターンに共通するのは、知識の不足ではなく、決める順番と判断の物差しの不足です。逆に言えば、順番を整えるだけで、やり直しの多くは防げます。

まずは、自分の企画が7つのうちどこで詰まっているか、1つだけ特定してみてください。それが最初の作業です。
